# Лабораторна робота 7. Автоматизовані тест-кейси на Playwright

- `tests/lz-codegen.spec.ts` – сценарій пошуку товару, перевірка ціни та наявності.
- `tests/lz7.spec.ts` – тест-дизайн (у коментарі) та автотест кошика: 7 кроків, 12 перевірок.

Запуск:

```
npm install
npx playwright install chromium
npx playwright test
npx playwright show-report
```
